# 分析准则

对每个素材先识别开头、展开、转折与结尾，再横向比较。逐条证据应可回到 source_id + segment_index；同一段原文可以支持不同维度，但不能把一个素材中的多个片段当作多个独立样本。

关注以下维度，只有输入支持时才生成规则：

| dimension | 观察与指令转化 |
| --- | --- |
| hook | 开场提出问题、制造反差、先下判断或引入日常场景；保留策略，不复用固定选题 |
| structure | 观点、原因、例子、反转、行动建议的组织顺序；区分高频结构和个别视频的特殊结构 |
| language | 称呼、口语程度、短句、设问、比喻、重复、连接词；不要仅给“口语化”之类无法执行的形容词 |
| rhythm | 文本中可观察的长短句切换、信息密度、递进和停顿位置；纯文本不能推断声线、镜头节奏或真实语速 |
| emotion | 情绪如何通过措辞和叙事变化表达；给出强度与适用情境，不编造创作者性格 |
| ending | 总结、反问、行动建议、留悬念等收束方式；区分真实互动习惯与平台模板 |
| boundaries | 创作者反复采用的表达边界；普遍的原创、事实和身份边界可以放在 Skill，但不得虚构为样本支持的个人特征 |

优先写出少量高价值、能迁移到陌生选题的规则。规则之间不能相互矛盾；不同模式可注明适用条件。不要要求每个选题都套同一口头禅。

confidence 用 high / medium / low。high 需要跨素材支持且无明显反例；medium 适用于反复出现但有条件差异；low 适用于单例或转写噪声较大的模式。limitations 至少给出一项实际局限，避免声称数据可以证明长期稳定性。

Creator-Skill 的写作流程应包括：明确选题与受众、核对用户给出的事实、按主题选择合适结构、输出可直接朗读的原创口播稿、按已提炼的规则自检。未知数字或案例不应填造，必要时标明待核实或采用不依赖具体数字的表达。
